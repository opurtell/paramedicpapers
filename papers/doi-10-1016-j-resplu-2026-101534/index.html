OHCA registry clock times run short

Quantifying discrepancies between EMS time intervals in the Swedish Registry for Cardiopulmonary Resuscitation and emergency medical dispatch data: A 10-year analysis
Resuscitation Plus · 2026-10 · Added 22 October 2026

Linking 56,969 Swedish OHCA registry records to dispatch-centre data showed unit response times matched almost exactly, but registry-recorded total response times ran a median 81 seconds shorter than the dispatch clock.

Study type
Cohort
Design
Retrospective registry linkage analysis
Participants
56,969 OHCA registry records linked to dispatch data, 2015–2024
Main finding
Unit response time differed by a median 0.3 seconds between sources, but total response time was systematically 80.9 seconds shorter in the registry, with large regional variation
Caveat
Single-country registry comparison where the two sources use different time definitions, so the gap reflects both recall bias and definitional drift
Bottom line
Context only

Why it matters in Australia (Medium relevance). Every Australian OHCA registry and service benchmark is built on the same kind of time intervals, so systematic drift between data sources matters to how performance is read.

Learning goal

Understand how inconsistent time definitions in out-of-hospital cardiac arrest data can distort quality improvement decisions.
