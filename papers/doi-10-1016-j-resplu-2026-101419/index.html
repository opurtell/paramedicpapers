Machine learning predicts paediatric code events

Validation of a Hospital-Wide Risk Stratification Model for Predicting Code Events Among Critically Ill Children
Resuscitation Plus · Added 27 July 2026

Study on: Validation of a Hospital-Wide Risk Stratification Model for Predicting Code Events Among Critically Ill Children. No abstract available for detailed assessment.

Study type
Cohort
Design
Single-centre retrospective external validation study (2020-2023)
Participants
5,254 paediatric encounters, of which 2.6% had at least one code event
Main finding
pCREST predicted code events within 12 h with c-statistic 0.80; 13-fold improvement in detection over outcome prevalence; high performance up to 18 h pre-event; transfer learning did not improve performance
Caveat
Single-centre retrospective validation; in-hospital PICU setting with low event rate (precision-recall curve 0.034)
Bottom line
Context only

Learning goal

Recognise early signs of deterioration in critically ill children to anticipate and prevent paediatric code events.
